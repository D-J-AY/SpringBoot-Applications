# Spring Boot Applications

A collection of backend applications built using **Java, Spring Boot, Spring Data JPA, Hibernate, REST APIs, and MySQL**. These projects demonstrate practical backend development, database design, authentication, authorization, and API development.


🚀 Projects

1. 🏥 Hospital Management System

A Spring Boot backend application designed to manage hospital-related operations.

**Key Features**

* Patient management
* Doctor management
* Hospital-related records management
* RESTful APIs
* Database integration
* CRUD operations

**Technologies**

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* REST APIs
* MySQL

### 3. 🥛 Dairy Sales and Distribution Management System

A business-oriented Spring Boot application designed to manage dairy product sales and distribution operations.

The system is designed around a real-world business workflow involving **products, product variants, shops, orders, and order items**.

**Key Features**

* Product management
* Product variant management
* Shop management
* Order management
* Order item management
* RESTful API development
* JWT-based authentication
* Role-based authorization
* Database persistence using JPA/Hibernate
* CRUD operations

**Technologies**

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* REST APIs
* Spring Security
* JWT
* MySQL
* Maven
